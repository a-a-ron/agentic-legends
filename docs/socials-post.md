🚀🎮 **Shipped: Agentic Legends (beta) — a browser platformer that teaches GitHub Copilot Proficiency and the Microsoft Pro Badge credential.**

You play a developer in **Codia**, a magical realm whose Sacred Mainline has fractured into unstable branches. Three mythical mentors hand you the gifts you need to merge it back together:

🍴 **Mona** → *Fork of Curiosity* (double-jump)
🦆 **Ducky** → *Bubbles of Clarity* (clear the fog)
🤖 **Copilot** → *Goggles of Insight* (reveal hidden platforms)

At the end of every level you face a **GitHub Copilot Proficiency knowledge check** before you can advance — how proficiency is verified, which levels earn a Microsoft Pro Badge, and what the badge represents.

🛠 **What's under the hood**
• Phaser 3 + TypeScript + Vite, deployed to GitHub Pages
• Variable-height jumps, sprint, and a hidden double-tap-Space leap
• Per-level dialogue, hearts, pause / mute / restart / quit
• Full-screen reward posters that match the official intro art
• Vitest suite + GitHub Actions CI on every PR
• Tag-driven release pipeline that auto-extracts CHANGELOG entries into the GitHub Release body and marks `0.x` builds as prereleases

🤝 **Built with GitHub Copilot CLI** as the pair-programmer end-to-end — from the first scene scaffold to the release workflow.
